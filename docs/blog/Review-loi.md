### Kiểm tra lỗi Schema (bắt buộc sau khi publish)

1. **Google Rich Results Test**  
   https://search.google.com/test/rich-results  
   → Dán URL hoặc code → xem lỗi và cảnh báo.

2. **Schema Markup Validator** (Schema.org)  
   https://validator.schema.org/

3. **Google Search Console** → Enhancements / Rich Results  
   Theo dõi sau 3–7 ngày.

**Lưu ý quan trọng:**
- Không gộp Product vào trong BlogPosting.
- Chỉ dùng `aggregateRating` khi số liệu là thật.
- Sau khi thêm Schema, luôn chạy Rich Results Test trước khi coi là xong.

Bạn có thể copy 2 khối trên thành 2 file Markdown và dùng ngay.
